AgentReel demo

Each agent was asked the same two things in a fresh checkout of this repository: explain the web export, then document it. A floating Zellij pane then exports the very recording you're watching. Each tab is a real recording, published with areel export --format web --single-file.

Select and copy any text. Click a marker on the timeline, or press [ and ], to jump between chapters. space plays and pauses.
